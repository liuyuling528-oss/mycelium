## 菌瘟不可手动净化（提交 be597f4，已上线验证）

用户反馈：「瘟菌肯定不能点击净化啊，你没把这个规则写清楚吗」——
判定为设计层纠正而非 bug（点击链路自测是通的）：免费点击净化 +90 养分
让等级规则形同虚设（瘟一点就没了，防火墙没有意义）。

规则改为：**瘟菌无法手动净化**，应对只有两条 ——
1. 防火墙：把关键菌丝练到 Lv8+（超过感染上限）免疫感染、挡住去路
2. 等自愈（42s，底线不变：绝不永久损失）

连带改动（净化的设计后果）：
- `config.js`：删 `BLIGHT.reward`，新增 `firewallNodes: 3`；
  m9「净化 12 处菌瘟」→「防火墙：同时拥有 3 个 Lv8+ 菌丝节点」（奖励不变：蔓延变慢）
- `sim.js`：`removeBlight` 降级为内部接口（无奖励/无计数/无浮字），
  仅供测试编排与清场；m9 判定改为数 Lv8+ 节点
- `WorldScene.js`：点击瘟菌 → `{ok:false, msg:'菌瘟净化不了 —— 等它自愈，或把周边菌丝练到 Lv8+ 挡住去路'}`
  （同时防误触强化：blighted 分支挡在 upgrade 前面）；
  tooltip 改为「无法手动净化 —— 等它自愈，或让 Lv8+ 菌丝挡住去路」
- `ui.js`：事件条/出现提示全部改为「无法净化」的说法
- `headless_sim.js`：respondToEvents 不再净化菌瘟（主动玩家的答案=防火墙，
  由 nodeFocus 落地），否则主动策略白赚净化奖励
- `autotest.js`：新增「瘟菌无法点击净化」（tryAct 拒绝 + 不误触强化 +
  内部移除不发奖励）与 m9 防火墙发奖/防重复 —— 119 → 123 项，全过

平衡模拟（1800s）：策略差异 3.56×（前 3.72）、主动/挂机 3.39×（前 3.37）——
不能净化后主动玩家靠深耕防火墙硬扛、挂机全 Lv0 网络烂得更久，差距没掉。
拥堵损耗 7.9%。

## 菌瘟等级规则（提交 d04bde1，已上线验证）

需求：菌瘟传染加等级维度 —— Lv N 的菌瘟只能传给等级 ≤ N 的邻居；自动感染封顶 Lv7。

实现（三处入口 + 两处提示）：
- `config.js`：`BLIGHT.maxLevel = 7`，注释块补充等级规则的设计意图（深耕 = 产能+吞吐+抗瘟）
- `sim.js`：
  - `blightableNodeIds`（初次滋生池）过滤 `level <= maxLevel` → Lv8+ 免疫滋生
  - `spreadBlights`：`srcLvl = Math.min(nd.level, cap)`，目标过滤 `t.level > srcLvl` → 只往下传；
    源头被手动强化超过上限时也按上限算（防「瘟中升级」钻空子）
- `WorldScene.js`：菌瘟提示加「只能传给 Lv N 及以下的邻居」；Lv8+ 健康节点提示「★ 等级高到菌瘟感染不了」
- `ui.js`：菌瘟出现日志带「只感染 Lv7 及以下」
- `autotest.js`：新增 10 条断言（109 → 119）。三条规则各带**正对照**
  （先证明菌瘟确实在扩散，"靶子没被感染"才不是空断言）：
  - 规则一：Lv≤7 源头 + Lv9 靶子 + 低级正对照邻居 → 300 轮扩散，靶子始终干净
  - 规则二：直接摆布 Lv10 源头（putBlight 绕过滋生池）+ Lv9 靶子 → 封顶生效
  - 规则三：全员 Lv9 → spawnBlight 返回 null；放开一个 Lv0 → 滋生点必是它
  - 等级摆布用 `S.lvlSaved` 记原始值，测完精确还原（capacity 与产出跟着复原）

验证：
- 自测 119/119 全过，零 JS 异常
- 平衡模拟 1800s：策略差异 3.72×（前 3.69）、主动/挂机 3.37×（前 3.33）——
  等级规则对整体平衡影响极小（低级菌仍是主要感染面），深耕流依旧榜首

踩坑（环境）：
- Bash 的 cwd 不会保持在项目目录（会话工作区是 Desktop\excel）——
  后台任务、重定向、http.server 的根目录全部要用**绝对路径**，否则静默 404/写错位置
- http.server 加 `--directory <项目路径>` 指定根目录
- 后半段 shim 环境开始丢命令（sleep/grep/dirname 报 command not found）——
  改用 Python（time.sleep + urllib）完成等待与线上探测
